# Uiua

**Status:** research/specialized

## Purpose
Tacit array programming and exploration of compact data transformation notation.

## Core model
Uiua is an array-oriented tacit language. Its value in this repository is partly conceptual: representation, composition, and data-oriented thought.

## Common mistakes
- assuming short symbols are automatically more understandable
- omitting shape/axis assumptions
- embedding operational side effects into dense array code

## Streamline
Keep array kernels small, document shape contracts, and use a host language for APIs, orchestration, and side effects.

## AI directive
Agents should state input/output shapes and semantic intent before generating dense tacit code.

Official: https://www.uiua.org/
