# Uiua Operating Card

**Route:** array programming, compact transformations, visual/data experimentation.

**Fast path:** interpreter/compiler → examples → reference tests → benchmark.

**Native authority:** Uiua implementation and language documentation.

**Pair with:** Python/Julia for production data pipelines; isolate Uiua experiments behind stable data contracts.

**Boundary:** explicit array shapes and conversion points.

**Avoid:** dense expressions without examples, hidden allocation/copy costs, untested glyph semantics.

**Reliability:** bounded inputs, deterministic transformations, reference outputs.

**Verify:** examples → property/reference tests → performance sample.

**AI learning loop:** learn primitives from the official reference; generate only after translating the desired transformation into array operations.

**Research:** https://www.uiua.org/docs · https://www.uiua.org/tutorial (single-page app: the server answers HTTP 404 to a link checker while the page renders — a status code is a rendering, not the identity)
