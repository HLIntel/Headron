# Gleam

Purpose: typed functional systems on the BEAM, concurrent services, and fault-tolerant applications.

Gleam combines static typing and functional programming with the Erlang runtime ecosystem and typed Actor abstractions.

Bounds still matter: external calls, queues, mailbox growth, retries, and memory-heavy payloads need explicit limits.

AI use: useful target for message-oriented services with explicit state boundaries.

Official: https://gleam.run/
