# Silq Operating Card

**Route:** quantum-language research, high-level quantum programming and automatic uncomputation concepts.

**Status:** research/experimental; do not treat ecosystem or tooling as production-stable.

**Fast path:** study language semantics → run reference implementation → compare against a classical/reference model.

**Native authority:** the `silq` reference implementation from ETH Zurich and its language paper; no other toolchain defines the semantics.

**Boundary:** distinguish reversible/uncomputed state from measurement and classical state.

**Avoid:** assuming research-language semantics map directly to current hardware SDKs.

**Verify:** small semantic examples → circuit/reference comparison → resource reasoning.

**AI learning loop:** read the language paper/reference before generating code; preserve mathematical semantics over syntactic convenience.

**Research:** https://silq.ethz.ch/ · https://github.com/eth-sri/silq
