# Models and Runtime Hosts

One contract, thin adapters for each place an agent runs. Adapters only tell a runtime where to
enter; rules stay in [`atlas.yaml`](../atlas.yaml), and every surface returns the same gate verdicts.

**Ready now:** [Google Antigravity](antigravity/README.md) · [Junie](junie/README.md) · [Claude Code](claude/README.md) · [OpenAI Codex](openai/README.md) ·
[GitHub Copilot](../AGENTS.md) · [Cursor and Grok Bot](cursor/README.md) ·
[OpenCode](opencode/README.md) · [Hermes](hermes/README.md) · [VS Code](vscode/README.md) ·
[Gemini CLI](gemini/README.md) · [goose](goose/README.md) · [Zed](zed/README.md) · [Aider](aider/README.md) · [Devin CLI](devin/README.md) ·
[Headron Desktop](headron-desktop/README.md) · [generic `llms.txt` clients](llm/README.md) · any MCP client.

Codex, GitHub Copilot, Cursor, OpenCode, Gemini CLI, goose, Zed, Aider and Devin CLI share the root [`AGENTS.md`](../AGENTS.md); no duplicate
policy is maintained per host. Every runtime and its adapter is also listed in the generated roster
in [MODEL.md](../MODEL.md). See [ROUTING.md](ROUTING.md) for task and host routing.

## Where you use it

<!-- BEGIN generated: settings (python scripts/atlas.py index --write) -->
| where you use it | what Headron does there |
|---|---|
| A chat with no tools | route the named file and name its gates from the pack; if either is unavailable, say so, never invent a command |
| A chat that keeps instructions | apply the Install block to the task; offer installation only if asked |
| An agent with a shell | run `python scripts/atlas.py gate <file>` in a checkout; without one, name the missing dependency |
| A repository's CI | call the reusable workflow; drift fails the pull request |
| A retrieval or RAG pipeline | run the retrieval_change gates (chunk boundaries, freshness stamp, hybrid recall, citations) so an answer rests on what was retrieved |
| An autonomous agent run | write a task contract; `python scripts/sandboxgen.py docker <contract>` prints its sandbox (no network, read-only root, only the worktree writable) |
| A chat or agent with memory | save verdicts by id (gate, change class, ledger entry) with the contract version, never a paraphrase: an id re-checks, a summary drifts |
<!-- END generated: settings -->
