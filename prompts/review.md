# Review Prompt

Use `MODEL.md` and the relevant domain guide before this template.

## Required sequence
1. read contract.
2. inspect diff.
3. check invariants.
4. check failure/resource bounds.
5. check dependencies/security.
6. run tests.
7. return findings by severity/evidence.

## Output
```text
status:
changed:
evidence:
verification:
risks:
next_action:
```
