# Security Review Prompt

Use `MODEL.md` and the relevant domain guide before this template.

## Required sequence
1. identify asset/trust boundary.
2. enumerate inputs/capabilities.
3. test validation/authz.
4. inspect secrets/dependencies.
5. check resource bounds.
6. verify exploit path and mitigation.
7. report residual risk.
