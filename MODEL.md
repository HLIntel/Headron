# MODEL.md

**Control plane version: 0.8.0**

Canonical model-aware operating layer for Claude, Cursor, OpenAI/Codex, OpenCode, Hermes, VS Code, and generic LLM providers.

Use the smallest model, host, tool, context, and permission surface that satisfies the task. Native language tooling remains authoritative; MCP is task-scoped.

Route code from `atlas.yaml` and the language guide before selecting a model or MCP profile. See [wiki/CODE-ROUTING.md](wiki/CODE-ROUTING.md) and [wiki/BRANCH-WORKTREES.md](wiki/BRANCH-WORKTREES.md).
