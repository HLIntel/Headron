# Repository Versioning

Current version: **0.3.1**

The version tracks the behavioral and instructional contract, not every wording edit.

## Same-commit rule
When an invariant changes, update `MODEL.md`, `VERSION`, the README contract, affected indexes/patterns/adapters, and commit them together.

## Sequence
- 0.1.0 foundation
- 0.2.0 advanced engineering structure
- 0.3.0 model control plane and dynamic AI integration
- 0.3.1 contract synchronization patch
- 0.4.0 next capability expansion
- 1.0.0 first stable control contract

Patch versions are appropriate for non-contract documentation and example corrections. If behavior or invariants change, use a minor/major increment as appropriate.
