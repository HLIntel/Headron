# Repository Versioning

Current version: **0.4.0**

The version tracks the behavioral/instructional contract rather than every wording edit.

## Same-commit rule
When an invariant, routing mechanism, security policy, verification requirement, or model-control rule changes, synchronize:
- `MODEL.md`
- `VERSION`
- `README.md`
- affected index/pattern/adapter
- affected language/system guide

Commit the synchronized set together.

## Sequence
- 0.1.0 foundation
- 0.2.0 advanced engineering structure
- 0.3.0 model control plane
- 0.3.1 contract synchronization
- 0.4.0 standardized language Atlas + dynamic engineering expansion
- 1.0.0 first stable control contract

Future versions should preserve the same rule: directive and repository reality must not intentionally diverge.
